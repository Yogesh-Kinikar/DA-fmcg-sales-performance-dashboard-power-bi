# 📊 FMCG Sales Performance Dashboard (Power BI)

## 🚀 Overview
This project presents an **end-to-end Power BI dashboard** analyzing FMCG retail performance across multiple countries, categories, brands, and channels.

The dashboard provides **actionable insights on sales, pricing strategy, demand drivers, and market segmentation**, helping stakeholders make data-driven decisions.

---

## 🎯 Objective
To analyze and visualize:
- Sales performance across regions and categories  
- Pricing & discount impact on demand  
- Demand drivers (weather, promotions, weekends)  
- Market segmentation across brands, channels, and SKUs  

---

## 🧾 Dataset Description
The dataset contains transactional-level data with the following key fields:

- 📅 Date, Year, Month, Weekday  
- 🌍 Country, City, Store  
- 🛍️ SKU, Category, Subcategory, Brand  
- 💰 Sales Metrics: Units Sold, Gross Sales, Net Sales  
- 💸 Pricing: List Price, Discount %, Margin  
- 📦 Inventory: Stock, Lead Time, Stock-out Flag  
- 🌦️ External Factors: Temperature, Rainfall  
- 🎯 Promotion & Holiday Indicators

## 📌 Key Business Insights
- Promotions contribute ~**10% of total sales**
- Hypermarkets dominate with **~54% sales share**
- Sales peak during **moderate weather conditions**
- Strong brand concentration in top performers
- Discounts increase sales but reduce margins → optimization needed

---

## 📈 How to Use
1. Download the `.pbix` file  
2. Open in **Power BI Desktop**  
3. Use slicers to filter by:
   - Country  
   - Year  
   - Category  
   - Brand  
4. Navigate across pages for insights
